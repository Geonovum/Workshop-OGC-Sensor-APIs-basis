# Workshop-OGC-Sensor-APIs-basis
Sensoren worden steeds vaker ingezet om onze leefomgeving te monitoren — denk aan luchtkwaliteit, waterpeilen of geluidsniveaus. Maar hoe zorg je ervoor dat die data ook echt bruikbaar is? In deze beginnersvriendelijke workshop maak je op een laagdrempelige manier kennis met de OGC SensorThings API.
